### Sobre

Comecei otimizando meu próprio aparelho por necessidade. Hoje pesquiso como cada fabricante limita CPU, térmica e renderização.

Meu foco: achar o que é escondido, medir de verdade e transformar em ajuste que funciona com ou sem root.

- **Ref:** Poco X5 Pro (778G / Adreno 642L)
- **Pesquisa:** MIUI / HyperOS, One UI, Motorola
- **Método:** Props via ADB + Shizuku, sem root

---

### CoreDroid — Principal Projeto

> **v1.7 Stable · 2 anos em desenvolvimento · via Shizuku**

App Android com 40+ ajustes em uma única interface, sem precisar de root. Performance, renderização, bateria e sistema.

<details>
<summary><b>Ver todos os recursos do CoreDroid</b></summary>
<br>

**Sistema:** Trava de Segurança (anti-reversão), Core Repair, Partitions Trimmer, Core Shell
**Performance:** Core Mode, Turbo Sched, PerfMagic, Supressão térmica
**Renderização:** Render Preload (System, ANGLE, Native, Game Driver), Vulkan / OpenGL, SkiaVK / SkiaGL
**Tela:** Desbloqueador de FPS, Anti burn-in, Otimização de UI e Launcher
**Memória:** Compressão de RAM, ZRAM/swap, ART / Dex2oat
**Outros:** Bateria, Rede, Áudio Hi-Fi, Core IA, Core Utils

</details>

<details>
<summary><b>Complemento WebUI + Perfis por Fabricante</b></summary>
<br>

**WebUI:** Ponte própria entre WebUI e Shizuku pra rodar ADB direto no app.
Módulos: Driver Booster (SurfaceFlinger), Performance Fixa, Alta Prioridade, Limpador de Memória ART, Desativar Conexões Google.

**Xiaomi:** Performance Mode, animações flagship, recursos do Game Turbo.
**Samsung:** Ativação Top App, remoção de telemetria e limites de FPS.
**Motorola:** Parâmetros de topo de linha, aceleração de touch e CPU/GPU.

</details>

### Pesquisa por Fabricante

- **Xiaomi / HyperOS:** Props `ro.*` e `persist.sys.*` via ADB sem root, blur e texturas em low-RAM, thermal menos restritivo
- **Samsung:** Modo Top App para limpeza de memória em uso pesado
- **Motorola:** Extração de recursos de ROM topo de linha

### Outros Projetos

**Módulos Magisk:** `Zenith Next` (gráficos/CPU/rede) e `ZRAM Focus` (RAM/swap)

**AxManager:** Módulos sem root para FPS, bateria e RAM

**Packs:**
- **Windows Pack:** Otimização completa de sistema, jogos e input (mouse/teclado). Média +40 FPS sem forçar hardware
- **Linux Pack:** Otimização de kernel, memória, energia e bateria com backup
- **ApkRushTool:** Tool Python para modding de APK
- **OPT-X / Newb X Dawn:** Texture e Shader otimizados pra ganho de FPS

### CoreDroid

Meu projeto principal, em desenvolvimento há mais de 2 anos (**v1.7 Stable**). Um app de otimização que funciona via Shizuku, sem root, com ajustes de CPU, GPU, memória, bateria, rede e áudio, além de perfis para Xiaomi, Samsung e Motorola.

O complemento é uma WebUI com uma ponte própria até o Shizuku, que executa comandos ADB direto pela interface web.

<br>

### Pesquisa

- **Xiaomi / HyperOS:** props de sistema aplicadas via ADB, sem root, e Blur em aparelhos low-RAM
- **Samsung / One UI:** ativação do modo Top App
- **Motorola:** recursos ocultos de áudio, toque e performance, extraídos de ROMs
